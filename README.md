# 🌐 Интернетометр — Telegram-бот

Бот на **Python 3.11+ (aiogram 3)** для проверки интернета. Умеет:

1. **🚀 Спидтест** — задержка (ping/jitter/потери), скорость загрузки и отдачи, провайдер, внешний IP, локация.
2. **📡 Мониторинг доступности** — следит за сайтами и присылает уведомление, когда ресурс упал или снова поднялся.
3. **📊 Счётчик трафика** — учитывает трафик, переданный через бота (спидтест, `/download`, сообщения) и показывает сеть хоста.
4. **📱 Web App** — мини-приложение внутри Telegram: спидтест прямо с телефона, калькулятор и информация о сети (опционально).

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Главное меню с кнопками и справка |
| `/speed [МБ]` | Замер скорости: ping, загрузка, отдача + оценка качества (по умолчанию до 200 МБ, ~8 с) |
| `/calc <размер> <скорость>` | Калькулятор: за сколько скачается файл |
| `/ping <хост>[:порт]` | TCP-пинг узла: средняя задержка, джиттер, потери |
| `/myip` | Внешний IP, провайдер, ASN и локация |
| `/history` | История ваших замеров скорости со средней |
| `/download <ссылка>` | Скачать файл, отправить его и посчитать трафик |
| `/monitor add <url> [сек]` | Добавить монитор (интервал по умолчанию 300 с) |
| `/monitor list` | Список мониторов со статусом |
| `/monitor del <id>` | Удалить монитор |
| `/monitor on <id>` / `/monitor off <id>` | Включить / выключить |
| `/monitor check <id>` | Проверить прямо сейчас |
| `/monitors` | То же, что `/monitor list` |
| `/traffic` | Показать счётчик трафика |
| `/id` | Ваш Telegram ID |
| `/stats` | Статистика бота (только для админов) |

## Быстрый старт

### 1. Получите токен
Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.

### 2. Установите зависимости

**Windows (проще всего):**
```bat
run.bat
```
Скрипт сам создаст `.venv`, установит зависимости и создаст `.env`.

**Вручную (Windows / Linux / macOS):**
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Настройте `.env`
Скопируйте `.env.example` в `.env` и укажите токен:
```env
BOT_TOKEN=123456789:AAExampleTokenReplaceMe
ADMIN_IDS=          # необязательно, ваш ID из /id
```

### 4. Запустите
```bash
python bot.py
```

## 📱 Веб-приложение (Telegram Web App)

Помимо кнопок, в меню бота можно добавить кнопку **«🎛 Открыть приложение»** —
полноценную мини-программу внутри Telegram: спидтест **с вашего телефона**
(браузер сам качает с Cloudflare), калькулятор загрузки и информация о сети.
Результат теста из приложения можно отправить боту кнопкой
«📤 Отправить результат в бот» — он запишется в историю `/history`.

Как включить:

1. Установите **cloudflared** (бесплатный туннель, без регистраций):
   https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. Запустите туннель к локальному серверу приложения:
   ```bash
   cloudflared tunnel --url http://localhost:8787
   ```
   В выводе появится адрес вида `https://xxxx.trycloudflare.com`.
3. Укажите его в `.env` и перезапустите бота:
   ```env
   WEBAPP_URL=https://xxxx.trycloudflare.com
   ```
4. Откройте `/start` в Telegram → появится кнопка «🎛 Открыть приложение».

Бот сам поднимает локальный сервер приложения (`webapp_server.py`)
на `WEBAPP_HOST:WEBAPP_PORT`, когда задан `WEBAPP_URL`. Если поле пустое —
кнопка и сервер не включаются.

> Вне Telegram приложение тоже открывается по адресу `http://localhost:8787`
> (сервер без туннеля), но отправка результата в бота будет недоступна.

## Как устроено

```
internetometer-bot/
├─ bot.py                    # точка входа, поллинг, запуск фоновых задач
├─ config.py                 # настройки из .env
├─ database.py               # SQLite: пользователи, трафик, мониторы (aiosqlite)
├─ handlers.py               # команды и логика ответов
├─ services/
│  ├─ netcheck.py            # TCP-пинг и проверка URL
│  ├─ speedtest_service.py   # спидтест через эндпоинты Cloudflare
│  ├─ monitor.py             # фоновый обход мониторов + уведомления
│  └─ traffic.py             # сетевые счётчики хоста (psutil, опционально)
├─ webapp_server.py           # локальный сервер веб-приложения (aiohttp)
├─ webapp/
│  ├─ index.html              # интерфейс мини-приложения
│  ├─ app.js                  # спидтест в браузере (Cloudflare), калькулятор
│  └─ style.css
├─ requirements.txt
├─ .env.example
└─ run.bat
```

### Почему Cloudflare, а не `speedtest-cli`?
Спидтест измеряется напрямую по HTTP(S) к публичным эндпоинтам
`speed.cloudflare.com`:
- `__down?bytes=…` — загрузка,
- `__up` — отдача,
- `meta` — IP, город, страна, провайдер.

Это асинхронно, не требует внешних бинарников и стабильно работает
из скриптов и контейнеров.

### Точность спидтеста
- Перед замером идёт «прогрев» соединения, чтобы отсечь стартовый провал
  TLS и разгон канала.
- Загрузка измеряется потоково в течение `SPEEDTEST_SECONDS` секунд,
  а не одним маленьким пакетом — короткий замер на быстром канале
  завышает/занижает скорость.
- Отдача измеряется пробником 4 МБ (он перекрывает сокетный буфер,
  из-за которого маленькая передача показывает ложную скорость)
  с добором объёма на быстрых каналах.

### Примечания
- Монитор считает ресурс «доступным», если получен любой HTTP-ответ.
- Первая проверка монитора не отправляет уведомление — она задаёт базовое состояние.
- `psutil` нужен только для статистики хоста в `/traffic` и `/stats`; без него бот продолжает работать.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обязательно) |
| `ADMIN_IDS` | пусто | ID админов через запятую |
| `DB_PATH` | `internetometer.db` | Путь к базе SQLite |
| `DEFAULT_SPEEDTEST_MB` | `200` | Верхняя граница объёма спидтеста |
| `MAX_SPEEDTEST_MB` | `1000` | Максимум, который можно указать в `/speed` |
| `SPEEDTEST_SECONDS` | `8` | Целевая длительность замера, с |
| `MAX_MONITORS_PER_USER` | `10` | Лимит мониторов на пользователя |
| `MAX_DOWNLOAD_MB` | `25` | Лимит размера для `/download` |
| `WEBAPP_URL` | пусто | Публичный HTTPS-адрес веб-приложения (туннель) |
| `WEBAPP_HOST` | `127.0.0.1` | Локальный адрес сервера приложения |
| `WEBAPP_PORT` | `8787` | Локальный порт сервера приложения |
